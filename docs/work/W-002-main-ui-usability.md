- 완료 조건: 변경이 `main`에 반영되고, 아래 ‘남은 일’의 실기기 확인 항목을 iPhone 홈 화면 앱에서 확인한다.

  - **`전체` 피드의 Product Hunt 비중.** 2026-09-28 기준 3일 창 149건 중 85건(57%)이 Product Hunt다. Show HN을 `전체`에서 뺀 이유(국내 소스가 묻힘, SPEC 6.2)와 비슷한 상황이지만 제품 정책이라 손대지 않았다. 이번 동점 정렬로 같은 실행 안에서는 Product Hunt가 뒤로 갔을 뿐 비중은 그대로다.

## 진행과 판단

### 배경과 범위

- 범위는 기존 화면의 사용성·표시·접근성이다. **새 기능과 새 축은 넣지 않았다.** [W-001](W-001-main-kill-test.md)의 kill test 원칙("기능을 더 넣지 말고 왜 안 열게 되는지부터")을 따랐다.
- 수집 파이프라인(`src/`), 데이터(`site/data/`, `state/`), 워크플로는 건드리지 않았다. [CLAUDE.md](../../CLAUDE.md)의 불변식과 무관하다.
- 지킨 제약: 읽음 상태·방문 기록 없음(SPEC 6.1), 평면 역시간순 리스트와 한 소스 축(6.2·6.3), 수집 내용 가공 금지(CLAUDE.md), 색은 토큰으로·대비 기준(6.6), 글자 크기 12~20px 램프, 런타임 의존성 0.

### 방법

- 배포 데이터(2026-09-28 07:32 KST 실행분)를 스크래치에 받고, 의존성 없는 Node 정적 서버로 `site/`를 띄워 헤드리스 Chrome 154를 CDP(Node 내장 WebSocket)로 조작했다. Chrome 확장은 연결되어 있지 않았다.
- 상태는 이렇게 재현했다. manifest만 바꾼 fixture 3종(소스 정지 / 조용한 경고 / 전역 멈춤), `data/*`를 3초 늦추는 서버, `data/*`가 전부 404인 서버, 상단 안전 영역 47px 에뮬레이션(`Emulation.setSafeAreaInsetsOverride`), 터치 에뮬레이션(`pointer: coarse` 성립 확인).
- 대비는 [site/style.css](../../site/style.css) 토큰을 읽어 WCAG 식으로 계산했다. 정렬은 V8(Node)과 JavaScriptCore(macOS `jsc`) 양쪽에서 돌려 봤다.
- 제 진단과 별개로 서브에이전트가 같은 화면을 독립 리뷰했다(Nielsen 10 휴리스틱 26/40, "Acceptable"). 둘이 따로 찾은 문제가 대부분 겹쳤다. 리뷰만 찾은 것 가운데 근거가 실측된 것을 2차로 반영했다. `impeccable` 결정론적 검출기는 권고 1건(다크 그림자 흐림 32px)만 냈다.
- 수정은 스크래치 사본에서 먼저 하고 검증한 뒤 저장소로 옮겼다. 같은 검증 스크립트를 수정 전 코드에 돌려 해당 항목이 실패하는 것도 확인했다(스크립트가 실제로 문제를 잡는지 확인).

### 검토했지만 하지 않은 것

- **뱃지 디자인 변경**(점 제거, 필터 중 숨김, 제목 뒤로 이동) — 리뷰 제안. 뱃지는 SPEC 6.2 예시에 있는 기존 디자인 요소라 사용자 판단으로 남긴다.
- **선택 칩 폭 고정** — 선택 시 점 때문에 11px 커져 이웃이 밀린다. 모든 칩에 공간을 잡으면 390px에서 소스 칩이 3줄로 넘어간다. 375px 이상에서는 선택해도 줄바꿈이 없다(리뷰는 360px에서 확인).
- **IME 조합 중 검색 보류** — 리뷰 제안. 마지막 음절이 조합 중이면 검색이 아예 안 돌아 더 느려진다. `영ㅅ` 순간 0건은 다음 입력에서 바로 바뀐다.
- **칩 줄 고정(sticky)** — 폰 화면의 1/3을 계속 차지한다.
- **읽음 표시·"지난 방문 이후"·`:visited` 흐리게** — SPEC 6.1·8 위반.
- **`전체` 검색에 Show HN 포함 / "Show HN 포함" 토글** — SPEC 6.2·6.3의 한 축 원칙 위반(우회 버그가 돌아온다).
- **`Show HN:`·`Show GN:` 접두어 떼기** — 원문 표시이고 SPEC 6.2 예시도 접두어를 둔다.
- **다크 팔레트를 `light-dark()`로 한 벌로 합치기** — 복제는 없어지지만 iOS 17.5 미만에서 색이 통째로 깨진다. 대신 두 블록이 복제라는 사실을 주석에 적었다.
- **데이터 나이를 건수 줄에 붙이기** — 실행 경계가 목록 맨 위에서 같은 정보(가장 최근 수집 시각)를 준다.
- **검색 진행을 live region으로** — 샤드마다 갱신돼 스크린 리더에 소음이다.

### 검증

모두 2026-09-28, macOS.

- 헤드리스 Chrome 154, 저장소 `site/` 대상 — **통과 45/45**(1차 27, 2차 18), 콘솔 오류 0. 390×844 @2x(터치 에뮬레이션)와 1280×900, 라이트·다크. 항목은 위 표의 조치마다 하나 이상이고, 회귀 방지 항목(행 본문 탭은 원문, Show HN 목록, 포커스 링)을 포함한다.
- 1차 스크립트를 수정 전 코드에 돌림 — 고친 항목이 실패하는 것을 확인했다. 세 번에 나눠 돌렸다: 앞 13개 중 2개 통과(그다음 새 `↗` 구조를 찾다 중단), 나머지 13개 중 4개 통과, 하네스를 고친 Enter·첫 방문 4개 중 1개 통과. 통과한 것은 동작이 바뀌지 않는 회귀 방지 항목(행 본문 탭, Show HN 목록, 포커스 링, 더 보기 글자색)이거나 원래도 성립하던 항목이다. **2차 스크립트는 수정 전 코드에 돌리지 않았다.**
